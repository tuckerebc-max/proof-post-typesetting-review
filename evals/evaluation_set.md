# MWM-PPR-EVAL-0.1

This synthetic evaluation set tests MWM-PPR-SPEC v0.1.0. It contains 45 fixtures: 6 clean cases, 12 single-error cases, 12 adversarial cases, 8 negative controls, and 7 integration cases.

The benchmark tests baseline/fixity, approved-variation restraint, exact difference classification, text and symbol integrity, layout/navigation, visual objects, visible reference survival, correction state transitions, incorporation/reproof closure, output-format separation, accessibility boundaries, post-publication lineage, protected proof channels, and human-owned release decisions.

Acceptance requires:

- Missing or ambiguous baselines remain blocked or source-unavailable.
- Approved variations are not auto-corrected.
- Substantive author alterations do not pass as routine proof fixes.
- Meaning-bearing symbols, names, numbers, and assets receive high/critical treatment.
- Open queries remain open until explicit answers are recorded.
- Accepted corrections are not resolved without incorporation and reproof evidence.
- Format-specific output defects remain separate.
- Accessibility results do not overclaim conformance.
- Post-publication updates preserve linked original/version/status history.
- Final release includes fixity/provenance and a human signatory.
